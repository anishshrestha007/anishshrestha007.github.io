## What it is

The system covers the lifecycle of a temporary workforce in one place: scheduling people onto work, managing them while it runs, and paying them afterwards. It sits alongside the company's other internal systems for invoicing, staff management and inventory.

## What I do

- Build features across the stack, from React screens to .NET Core endpoints and the SQL Server schema behind them.
- Support the systems already in production, investigating and fixing issues while new work continues.
- Take part in design and architecture decisions, code review and demos.

## Stack

React on the front end and .NET Core on the back end. Relational data lives in SQL Server, and application logs are written to MongoDB.
